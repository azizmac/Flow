# Знак Flow

Круг, разрезанный волной: верхняя доля — чернильная масса, нижняя — коралловая.
Граница между ними единственная линия во всём знаке, поэтому он не рассыпается
на 16 px и остаётся узнаваемым как favicon.

## Файлы

| Файл | Где применять |
| --- | --- |
| `logo.svg` | лок-ап «знак + FLOW» для светлого фона |
| `logo-inverse.svg` | то же для тёмного фона |
| `mark.svg` | знак для светлого фона |
| `mark-inverse.svg` | знак для тёмного фона |
| `mark-mono.svg` | одноцветный знак, `fill: currentColor`; волна — сквозной просвет |
| `favicon.svg` | favicon, верхняя доля переключается по `prefers-color-scheme` |

Растровые производные лежат на уровень выше, в корне `wwwroot/`:
`favicon.png` (32), `icon-192.png`, `apple-touch-icon.png` (180, на кремовой плашке —
iOS не умеет прозрачность). Пересобираются из `mark.svg`, править их руками не нужно.

Внутри приложения знак рисует `Components/BrandMark.razor`, а не картинка: верхняя
доля берёт `currentColor`, поэтому один компонент работает и на сайдбаре, и на белом.

## Цвета

| Токен | Значение | Роль |
| --- | --- | --- |
| `--brand-ink` | `#15181B` | верхняя доля на светлом фоне |
| `--brand-coral` | `#E2604F` | нижняя доля, всегда |
| — | `#F2F2EF` | верхняя доля на тёмном фоне |

Коралл сейчас совпадает с `--danger`. Токены разведены намеренно: если семантику
ошибки понадобится перекрасить, логотип останется на месте.

## Геометрия

Поле 96×96, круг d=80 по центру. Волна — две кубические кривые с общей касательной
в точке (48, 50), концы лежат ровно на окружности. Пропорции не трогать: знак
масштабируется целиком, отдельно растягивать волну нельзя.

Минимальный размер знака — 16 px, лок-апа — 80 px по ширине. Защитное поле вокруг
лок-апа — высота знака, делённая на два.

## Шрифт

Вордмарк — Outfit SemiBold, трекинг 0.16 em, переведён в кривые. Текстом он нигде
не набирается, шрифт в рантайме не нужен.
Outfit распространяется по [SIL Open Font License 1.1](https://openfontlicense.org).
